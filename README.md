### 🧠 What I actually do

- 🎭 Build **actor-model backends** in C#/.NET with Proto.Actor — because shared mutable state is a crime and I'm the cop.
- 📡 Ship **edge agents & monitoring servers** that babysit fleets of devices over MQTT, gRPC and GraphQL.
- 🕸️ Craft **GraphQL APIs** (HotChocolate) so the frontend can ask for exactly what it wants and still complain.
- ⚛️ Build **React + TypeScript** frontends when the backend is done and nobody else volunteered.
- 🐳 Containerize everything. If it doesn't run in Docker, does it even exist?
- 🧪 Spin up PoCs faster than product can rename them.
